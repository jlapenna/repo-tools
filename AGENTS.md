# repo-tools Agent Guide

This file is a compact router. Load the owning skill or document instead of
copying procedures into always-loaded context.

## Start Here

- Read `ARCHITECTURE.md` before changing command, plugin, or provider
  boundaries.
- Use `docs/README.md` to locate durable documentation and the generated
  interface inventory.
- Before any Git mutation, read
  `plugins/repo-tools/skills/worktree-hygiene/SKILL.md` and work in a dedicated
  linked worktree.
- Use the skill that matches the task; skills are source, not generated copies.

## Task Routes

| Task | Read first | Proof |
| --- | --- | --- |
| Worktree/process safety | `plugins/repo-tools/skills/worktree-hygiene/SKILL.md` | matching shell tests |
| CI or auto-merge monitoring | `plugins/repo-tools/skills/github-ci-monitor/SKILL.md` | watcher tests |
| Land a PR | `plugins/repo-tools/skills/land-pr/SKILL.md` | protected current-head lifecycle |
| Test/CI policy | `plugins/repo-tools/skills/testing-policy/SKILL.md` | policy examples and consumer checks |
| Harness, documentation, or skill upkeep | `plugins/repo-tools/skills/harness-maintenance/SKILL.md` | native docs checks and observed consumer use |
| Renovate maintenance | `plugins/repo-tools/skills/renovate-maintenance/SKILL.md` | skill-defined queue evidence |
| Add or change a CLI | `ARCHITECTURE.md`, matching `bin/*.test.*` | focused test, then `pnpm test` |
| Change plugin manifests | `ARCHITECTURE.md`, `plugins/manifests.test.mjs` | manifest and docs checks |
| Change shared ESLint behavior | `eslint/`, consumer contract | build and rule tests |

## Boundaries

- `bin/` owns portable commands and their adjacent tests.
- `plugins/repo-tools/skills/` owns shared workflow guidance.
- `eslint/` owns the shared lint implementation and consumer contract.
- `docs/interfaces.md` is generated by `repo-docs`; do not hand-edit it.
- Keep this repository agent-runtime-neutral: no fleet identity, session state,
  or Agent LCARS runtime behavior.

When a durable rule changes, update its owner and executable proof. Do not
grow this router into another workflow manual.
